Webhook

Para onde mandar os eventos desta variação. Dispara do servidor, então a URL nunca aparece em página nenhuma.

Configura-se direto no Supabase desta variação, não aqui. A chave usada por esta página é a mesma que fica no código do quiz, que é público: se desse para editar daqui, qualquer pessoa que lesse aquele código poderia redirecionar os seus leads.

Como: Supabase > Table Editor > quiz_config > preencha webhook_url e webhook_quando. Depois habilite pg_net em Database > Extensions e descomente o trigger no fim do supabase-c.sql.
