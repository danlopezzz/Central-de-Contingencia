Para onde mandar os eventos. Fica guardado no banco e dispara do servidor, então a URL nunca aparece no código do quiz.

Salvar aqui só guarda a configuração. Para o disparo acontecer, habilite a extensão pg_net no Supabase e ative o trigger que está comentado no fim do arquivo supabase-tracking.sql.

Os dados são anônimos: nenhum nome, telefone ou e-mail é coletado.
A sessão é um identificador aleatório gerado no navegador de quem responde.
